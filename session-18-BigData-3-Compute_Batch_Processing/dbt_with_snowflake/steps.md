    "# dbt Core + Snowflake 本地环境搭建指南\n",
    "\n",
    "> **基于 dbt 官方 Quickstart 教程改编，使用 dbt Core（免费开源）替代 dbt Cloud**  \n",
    "> **数据集**：jaffle_shop（公开 S3 CSV）— 不需要 Snowflake Marketplace  \n",
    "> **预计耗时**：30-45 分钟  \n",
    "> **费用**：$0（Snowflake 30 天 trial + dbt Core 开源免费）\n",
    "\n",
    "---\n",
    "\n",
    "## 前置条件\n",
    "\n",
    "- Python 3.9+（推荐 3.11）\n",
    "- 一个 Snowflake trial 账号（选 Enterprise 版，确保有 ACCOUNTADMIN 权限）\n",
    "  - 注册地址：https://signup.snowflake.com/\n",
    "  - 任何 cloud provider 和 region 都行\n",
    "- Git（可选但推荐）\n",
    "\n",
    "---\n",
    "\n",
    "## Step 1：安装 dbt Core + Snowflake adapter\n",
    "\n",
    "```bash\n",
    "# 建议用 venv 隔离\n",
    "python -m venv dbt-env\n",
    "source dbt-env/bin/activate        # Mac/Linux\n",
    "# dbt-env\\Scripts\\activate         # Windows\n",
    "\n",
    "pip install dbt-core dbt-snowflake\n",
    "\n",
    "# 验证安装\n",
    "dbt --version\n",
    "```\n",
    "\n",
    "你应该能看到 dbt Core 和 dbt-snowflake 的版本号。\n",
    "\n",
    "---\n",
    "\n",
    "## Step 2：在 Snowflake 中加载 sample data\n",
    "\n",
    "登录 Snowflake trial 账号，打开一个 SQL Worksheet，依次运行以下 SQL。\n",
    "\n",
    "### 2.1 创建 warehouse、database、schema\n",
    "\n",
    "```sql\n",
    "CREATE WAREHOUSE transforming;\n",
    "CREATE DATABASE raw;\n",
    "CREATE DATABASE analytics;\n",
    "CREATE SCHEMA raw.jaffle_shop;\n",
    "CREATE SCHEMA raw.stripe;\n",
    "```\n",
    "\n",
    "### 2.2 创建表并从 S3 加载数据\n",
    "\n",
    "**customers 表：**\n",
    "\n",
    "```sql\n",
    "CREATE TABLE raw.jaffle_shop.customers\n",
    "( id INTEGER,\n",
    "  first_name VARCHAR,\n",
    "  last_name VARCHAR\n",
    ");\n",
    "\n",
    "COPY INTO raw.jaffle_shop.customers (id, first_name, last_name)\n",
    "FROM 's3://dbt-tutorial-public/jaffle_shop_customers.csv'\n",
    "FILE_FORMAT = (\n",
    "    TYPE = 'CSV'\n",
    "    FIELD_DELIMITER = ','\n",
    "    SKIP_HEADER = 1\n",
    ");\n",
    "```\n",
    "\n",
    "**orders 表：**\n",
    "\n",
    "```sql\n",
    "CREATE TABLE raw.jaffle_shop.orders\n",
    "( id INTEGER,\n",
    "  user_id INTEGER,\n",
    "  order_date DATE,\n",
    "  status VARCHAR,\n",
    "  _etl_loaded_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP\n",
    ");\n",
    "\n",
    "COPY INTO raw.jaffle_shop.orders (id, user_id, order_date, status)\n",
    "FROM 's3://dbt-tutorial-public/jaffle_shop_orders.csv'\n",
    "FILE_FORMAT = (\n",
    "    TYPE = 'CSV'\n",
    "    FIELD_DELIMITER = ','\n",
    "    SKIP_HEADER = 1\n",
    ");\n",
    "```\n",
    "\n",
    "**payment 表：**\n",
    "\n",
    "```sql\n",
    "CREATE TABLE raw.stripe.payment\n",
    "( id INTEGER,\n",
    "  orderid INTEGER,\n",
    "  paymentmethod VARCHAR,\n",
    "  status VARCHAR,\n",
    "  amount INTEGER,\n",
    "  created DATE,\n",
    "  _batched_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP\n",
    ");\n",
    "\n",
    "COPY INTO raw.stripe.payment (id, orderid, paymentmethod, status, amount, created)\n",
    "FROM 's3://dbt-tutorial-public/stripe_payments.csv'\n",
    "FILE_FORMAT = (\n",
    "    TYPE = 'CSV'\n",
    "    FIELD_DELIMITER = ','\n",
    "    SKIP_HEADER = 1\n",
    ");\n",
    "```\n",
    "\n",
    "### 2.3 验证数据\n",
    "\n",
    "```sql\n",
    "SELECT * FROM raw.jaffle_shop.customers;  -- 应该看到 100 行\n",
    "SELECT * FROM raw.jaffle_shop.orders;     -- 应该看到 99 行\n",
    "SELECT * FROM raw.stripe.payment;         -- 应该看到 113 行\n",
    "```\n",
    "\n",
    "---\n",
    "\n",
    "## Step 3：初始化 dbt 项目\n",
    "\n",
    "```bash\n",
    "# 在你想放项目的目录下运行\n",
    "dbt init jaffle_shop\n",
    "```\n",
    "\n",
    "dbt 会交互式地问你几个问题：\n",
    "- Which database would you like to use? → 输入对应 **snowflake** 的编号\n",
    "- account → 你的 Snowflake account identifier（见下方说明）\n",
    "- user → 你的 Snowflake 用户名\n",
    "- password → 你的密码（或选择其他认证方式）\n",
    "- role → 留空或输入 `ACCOUNTADMIN`\n",
    "- warehouse → `transforming`\n",
    "- database → `analytics`\n",
    "- schema → `dbt_<你的名字>`（如 `dbt_chengyang`）\n",
    "- threads → `4`\n",
    "\n",
    "### 如何找到 Snowflake account identifier\n",
    "\n",
    "看你的 Snowflake URL：\n",
    "- 如果是 `https://abc12345.us-east-1.snowflakecomputing.com` → account 是 `abc12345.us-east-1`\n",
    "- 如果是 `https://app.snowflake.com/us-east-1.aws/abc12345` → account 是 `abc12345.us-east-1.aws`\n",
    "\n",
    "**不要包含** `snowflakecomputing.com` 部分。\n",
    "\n",
    "### 验证连接\n",
    "\n",
    "```bash\n",
    "cd jaffle_shop\n",
    "dbt debug\n",
    "```\n",
    "\n",
    "你应该看到 `All checks passed!`。如果连接失败，检查 `~/.dbt/profiles.yml` 里的配置。\n",
    "\n",
    "---\n",
    "\n",
    "## Step 4：配置项目\n",
    "\n",
    "编辑项目根目录下的 `dbt_project.yml`：\n",
    "\n",
    "```yaml\n",
    "name: 'jaffle_shop'\n",
    "version: '1.0.0'\n",
    "\n",
    "profile: 'jaffle_shop'\n",
    "\n",
    "model-paths: [\"models\"]\n",
    "analysis-paths: [\"analyses\"]\n",
    "test-paths: [\"tests\"]\n",
    "seed-paths: [\"seeds\"]\n",
    "macro-paths: [\"macros\"]\n",
    "snapshot-paths: [\"snapshots\"]\n",
    "\n",
    "models:\n",
    "  jaffle_shop:\n",
    "    +materialized: table\n",
    "```\n",
    "\n",
    "删除 `models/example/` 目录（dbt init 自动生成的示例文件）：\n",
    "\n",
    "```bash\n",
    "rm -rf models/example\n",
    "```\n",
    "\n",
    "---\n",
    "\n",
    "## Step 5：创建 staging models\n",
    "\n",
    "### 5.1 声明 sources\n",
    "\n",
    "创建 `models/_sources.yml`：\n",
    "\n",
    "```yaml\n",
    "sources:\n",
    "  - name: jaffle_shop\n",
    "    database: raw\n",
    "    schema: jaffle_shop\n",
    "    tables:\n",
    "      - name: customers\n",
    "      - name: orders\n",
    "\n",
    "  - name: stripe\n",
    "    database: raw\n",
    "    schema: stripe\n",
    "    tables:\n",
    "      - name: payment\n",
    "```\n",
    "\n",
    "### 5.2 创建 staging 层\n",
    "\n",
    "创建 `models/staging/` 目录，然后添加以下文件：\n",
    "\n",
    "**`models/staging/stg_customers.sql`**\n",
    "\n",
    "```sql\n",
    "SELECT\n",
    "    id AS customer_id,\n",
    "    first_name,\n",
    "    last_name\n",
    "FROM {{ source('jaffle_shop', 'customers') }}\n",
    "```\n",
    "\n",
    "**`models/staging/stg_orders.sql`**\n",
    "\n",
    "```sql\n",
    "SELECT\n",
    "    id AS order_id,\n",
    "    user_id AS customer_id,\n",
    "    order_date,\n",
    "    status\n",
    "FROM {{ source('jaffle_shop', 'orders') }}\n",
    "```\n",
    "\n",
    "**`models/staging/stg_payments.sql`**\n",
    "\n",
    "```sql\n",
    "SELECT\n",
    "    id AS payment_id,\n",
    "    orderid AS order_id,\n",
    "    paymentmethod AS payment_method,\n",
    "    status,\n",
    "    -- amount 在原始数据中是以分为单位，转换成美元\n",
    "    amount / 100.0 AS amount\n",
    "FROM {{ source('stripe', 'payment') }}\n",
    "```\n",
    "\n",
    "### 5.3 运行 staging models\n",
    "\n",
    "```bash\n",
    "dbt run\n",
    "```\n",
    "\n",
    "你应该看到 3 个 model 都成功了。去 Snowflake 里检查 `analytics.dbt_chengyang` schema，应该能看到 3 张新表。\n",
    "\n",
    "---\n",
    "\n",
    "## Step 6：创建 marts model（使用 ref）\n",
    "\n",
    "创建 `models/customers.sql`：\n",
    "\n",
    "```sql\n",
    "WITH customers AS (\n",
    "    SELECT * FROM {{ ref('stg_customers') }}\n",
    "),\n",
    "\n",
    "orders AS (\n",
    "    SELECT * FROM {{ ref('stg_orders') }}\n",
    "),\n",
    "\n",
    "payments AS (\n",
    "    SELECT * FROM {{ ref('stg_payments') }}\n",
    "),\n",
    "\n",
    "customer_orders AS (\n",
    "    SELECT\n",
    "        customer_id,\n",
    "        MIN(order_date) AS first_order_date,\n",
    "        MAX(order_date) AS most_recent_order_date,\n",
    "        COUNT(order_id) AS number_of_orders\n",
    "    FROM orders\n",
    "    GROUP BY 1\n",
    "),\n",
    "\n",
    "customer_payments AS (\n",
    "    SELECT\n",
    "        orders.customer_id,\n",
    "        SUM(payments.amount) AS total_amount\n",
    "    FROM orders\n",
    "    LEFT JOIN payments ON orders.order_id = payments.order_id\n",
    "    GROUP BY 1\n",
    "),\n",
    "\n",
    "final AS (\n",
    "    SELECT\n",
    "        customers.customer_id,\n",
    "        customers.first_name,\n",
    "        customers.last_name,\n",
    "        customer_orders.first_order_date,\n",
    "        customer_orders.most_recent_order_date,\n",
    "        COALESCE(customer_orders.number_of_orders, 0) AS number_of_orders,\n",
    "        COALESCE(customer_payments.total_amount, 0) AS customer_lifetime_value\n",
    "    FROM customers\n",
    "    LEFT JOIN customer_orders USING (customer_id)\n",
    "    LEFT JOIN customer_payments USING (customer_id)\n",
    ")\n",
    "\n",
    "SELECT * FROM final\n",
    "```\n",
    "\n",
    "运行：\n",
    "\n",
    "```bash\n",
    "dbt run\n",
    "```\n",
    "\n",
    "dbt 会自动推断依赖顺序：先跑 `stg_customers`、`stg_orders`、`stg_payments`，最后跑 `customers`。\n",
    "\n",
    "---\n",
    "\n",
    "## Step 7：添加 data tests\n",
    "\n",
    "创建 `models/_models.yml`：\n",
    "\n",
    "```yaml\n",
    "models:\n",
    "  - name: stg_customers\n",
    "    columns:\n",
    "      - name: customer_id\n",
    "        data_tests:\n",
    "          - not_null\n",
    "          - unique\n",
    "\n",
    "  - name: stg_orders\n",
    "    columns:\n",
    "      - name: order_id\n",
    "        data_tests:\n",
    "          - not_null\n",
    "          - unique\n",
    "      - name: status\n",
    "        data_tests:\n",
    "          - accepted_values:\n",
    "              values: ['placed', 'shipped', 'completed', 'return_pending', 'returned']\n",
    "\n",
    "  - name: customers\n",
    "    columns:\n",
    "      - name: customer_id\n",
    "        data_tests:\n",
    "          - not_null\n",
    "          - unique\n",
    "```\n",
    "\n",
    "运行测试：\n",
    "\n",
    "```bash\n",
    "dbt test\n",
    "```\n",
    "\n",
    "所有测试应该都通过。\n",
    "\n",

    "\n",
    "## Step 8：生成文档\n",
    "\n",
    "```bash\n",
    "dbt docs generate\n",

    "│   │   ├── stg_customers.sql\n",
    "│   │   ├── stg_orders.sql\n",
    "│   │   └── stg_payments.sql\n",
    "│   └── customers.sql       # marts 层\n",
